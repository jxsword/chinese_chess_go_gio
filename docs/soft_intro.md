# 中国象棋 Ultra（Gio 版）功能说明

> 文档定位：面向使用者/评估者的软件功能说明。事实源为上游 Electron 版 `01-需求规格说明书`（E-F01~F42）、
> 本仓 `design_docs/`（00~11）与 `docs/PROGRESS.md`；行为口径与上游 v1.0.0-rc1 逐位一致，
> 仅两处既定设计差异（重复局面裁决前置、LLM 思维链强制关闭），见 §10。

## 1. 软件简介

**中国象棋 Ultra** 是一款功能完整的中国象棋桌面应用，由 **Go 语言 + Gio 全自绘 GUI** 实现，
编译为**单个可执行文件**（无 WebView、无运行时依赖、无前端 bundle），支持 Windows / Linux / macOS 三平台。

应用覆盖中国象棋的全部核心玩法与进阶生态：

- **五种对局模式**：双人对弈、人机对战（内置 AI）、人机对战（大模型）、大模型对战（LLM vs LLM）、残局挑战；
- **完整规则内核**：七种棋子全部走法、将死/困毙判定、长将与重复局面裁决；
- **内置 AI 引擎**：Negamax + Alpha-Beta + 迭代加深，五档难度，Zobrist 重复局面治理；
- **大模型对弈**：接入任意 OpenAI 兼容端点，SSE 流式输出、五层过滤管线、引擎参谋制（候选/护航模式）；
- **残局求解器**：AND/OR 迭代加深杀棋搜索，可证明无解；
- **棋谱生态**：XQF/PGN 解析、14 万局语料库浏览、棋谱记录库、演示播放器、残局工作室与视觉识图。

## 3. 对局通用能力（五种模式共用）

### 3.1 棋盘与走子交互

- 棋盘全自绘：木色底、10×9 线路（中间纵线在楚河汉界区断开）、九宫斜线、炮位/兵位标记、
  "楚河/汉界"纵排文字、红方汉字纵线号（一~九，右→左）、黑方数字纵线号（1~9，左→右）；
- 点击选中棋子 → **合法目标点高亮**（绿色圆点/角标，来自规则内核白名单精确匹配）→ 点击目标格落子；
- 落子带 **220ms 两阶段飞行动画**（easeOutCubic 缓动，被吃子保持可见直至落定）；
  动画期间棋盘点击被忽略，动画结束（帧时间戳判定）才真正落子，防连点错乱；
- 选中态高亮环、上一步（lastMove）标记、将军时被将方帅/将格红色高亮；
- 点空白处或再次点击选中子 = 取消选中；
- 终局后棋盘禁手，覆盖终局结算横幅。

### 3.2 对局信息与操作（四对局页共用侧板）

- 对局信息：当前回合、步数、用时计时器（每秒累计，终局后暂停，`mm:ss` 格式）、将军标记、
  状态条四态（对局结束 / AI·LLM 思考中 / 被将军 / 等待玩家）；
- "显示走法记录"开关 + 走法列表（中文记谱）；
- 操作按钮：**新游戏**（确认对话框，清空该模式存档、作废在途异步请求）、
  **悔棋**（双人悔一手；人机模式悔一整轮——先撤 AI 手再撤玩家手；AI/LLM 思考期间不可悔）、
  **保存棋局**、**分享棋局**（复制对局文本到剪贴板）；
- 侧板采用"滚动区 + 固定底部按钮行"布局，滚动时操作按钮始终可见。

### 3.3 悔棋、新局与自动保存（E-F05/F06/F07）

- **每模式一局存档**（SQLite `saved_games` 表，按 5 种模式分桶）：退出页面、窗口失焦、
  最小化、关闭窗口时自动保存；再次进入页面恢复对局（重放逐手重建，非法"脏记录"跳过并计数）；
- 已分胜负的存档视为死局，恢复时自动删除后开新局；全局"自动保存棋局"开关（默认开）；
- 棋谱来源的对局不写模式存档桶（`canSave` 门控），避免污染残局挑战进度；
- 恢复取档期间先锁输入，取档完成按恢复决策应用后解锁；存档失败在状态条提示，不吞错不阻塞交互。

### 3.4 重复局面裁决（本版前置到核心对局，E-F01 增量）

中国象棋传统"自然限着/长捉"不实现（与上游/原版口径一致），但**长将与重复局面裁决**完整实现：

- 同一局面第 2 次重复且单方长将 → 非阻塞 toast 警告（不打断对局）；
- 第 3 次重复且单方长将 → 判负（复用终局结算弹窗，文案含判负方）；
- 第 3 次重复且双方全程将军 → 不变作和；无人全程将军 → 判和
  （对手为 AI/LLM 时自动接受；对手是玩家时弹确认框：接受和棋 / 变着继续）；
- 玩家曾拒绝和棋后第 4 次重复 → 强制判和；
- 悔棋/新局重置拒绝记录与未决确认框。

### 3.5 界面与输入

- **中文 IME**：所有文本输入框支持中文输入法（预编辑渲染）；WSLg 环境下键盘输入受限，
  提供"从 Windows 剪贴板粘贴"按钮作为可靠中文输入路径；
- **界面缩放**：全局设置内 100%~200% 五档缩放（相对系统检测值），即刻生效并持久化；
- 系统剪贴板写入（分享/导出）、系统文件/目录选择对话框（Linux zenity/kdialog、
  Windows 原生对话框、macOS osascript），页面内路径输入保留为兜底。

## 4. 双人对弈与人机对战

### 4.1 双人对弈（E-F02）

同屏红黑轮流走子，包含 §3 全部通用能力（合法高亮、动画、计时、悔棋一手、自动保存、分享）。

### 4.2 人机对战（内置 AI，E-F11）

- **五档难度**：初级/中级/高级/专家/大师——对应搜索深度 2~6、时限 300ms~5s、
  低难度带根节点随机窗口（避免每局走法雷同）；引擎思考在独立 goroutine，不阻塞界面；
- **执红/执黑可选**：选执黑时 AI 执红先行；引擎类型与难度在侧板"对手"区点选；
- 思考中无独立取消按钮：悔棋/新游戏/返回即取消在途请求并丢弃迟到结果（对齐上游口径）；
  AI 应手落盘后终点棋子补 220ms 视觉飞行，与点击走子观感一致；
- 思考呈现有 300ms 最小时长（避免高难度引擎"秒回"造成的观感突兀，呈现层行为）；
- 残局挑战进入的人机对战：胜负时弹"通关/惜败"对话框（防重入）；
- 难度 5（深度 6）单手应答实测 ≤7.5s（性能门），实际约 1.5s。

## 5. 残局挑战（选关 + 演示）

主页"残局选关"入口即**语料库浏览页**：

- **语料下载引导**：语料缺失时提供内置下载入口，进度条可取消；取消后保留半成品与 ETag，
  重试续传（复制物内建 SSRF 白名单 + zip-slip 防护，仅 HTTPS）；
- **分类浏览**：按语料分类列目（关卡卡显示标题/步数/难度投影），难度筛选与排序；
- **XQF 面板**：搜索框（中文输入可用）、"仅残局"开关、难度与排序 chips、分批解析进度条（每批 128 个文件，UI 可取消）；
- **PGN 长列表**：14 万局规模虚拟化连续滚动（实测滚动帧率 76~87 FPS），搜索跳转；
- **重放器**：行点击进入——步进控制 + 800ms 自动播放 + 走法列表 + 导出 PGN（复制）+ 进入对战；
- **残局挑战**：进入关卡后先尝试破解（首着获胜判定），亦可选择"演示播放"观看解法
  （步进/自动/回退控制条，速度档位与循环播放）。

## 6. 大模型对弈

### 6.1 接入点配置（E-F20）

- **红/黑/助手三个独立槽位**，每槽位四字段：baseUrl、apiKey、模型名、端点预设；
- **端点预设**：智谱 GLM / DeepSeek / Kimi / OpenRouter / OpenAI / 百炼 / 自定义（视觉预设另列）；
  选择预设自动补全 URL（`/chat/completions`）与请求参数；
- **API Key 安全**：仅存操作系统凭据库（keyring），无 keyring 时回退 0600 明文文件；
  界面回显掩码（`****`+末 4 位），掩码回写不会覆盖真实 Key；Key 不落日志；
- **测试连接**按钮；配置改动防抖自动保存；配置不完整（缺 baseUrl 或模型）时对战页禁止开始；
- **思维链强制关闭**：请求构造层按预设恒发关闭参数（如 DashScope `enable_thinking:false`、
  GLM-4.5+ `thinking:{type:disabled}`），**界面不提供任何开启开关**——保证输出可直接解析为着法（设计差异二，见 §10）。

### 6.2 人机 LLM 对战（E-F21）

- 玩家执红，黑方由 LLM 走子；LLM 收到 **Prompt v2 协议**：ASCII 棋盘图 + 走法历史注解
  （中文记法/吃子/将军）+ "分析:"思路段（≤100 字）+ 整局历史 ≤60 着 + 循环警示；
- **SSE 流式**：模型回复逐字追加到侧板消息区实时显示；
- **五层过滤管线**：模型回复经围栏剥离 → 着法解析 → **与本地规则白名单精确匹配**（非法即拒）等
  五层过滤，防幻觉着法；
- **引擎参谋制**（E-F41，三模式）：
  - *off*：P0 基线，纯 LLM 决策；
  - *candidate（候选）*：引擎给出 Top-K 短名单，LLM 只能从中选择；
  - *gate（护航）*：LLM 自由选择，引擎按 `否决阈值 = 80 + 3.2×棋力旋钮` 厘兵否决
    （棋力 0~100 旋钮，100 不否决）；否决后带理由再问一次，仍超阈值则引擎最佳代走；
- 配置项：空闲超时（30/60/120/180/300s）、重试次数（1/3/5）、降级策略（**内置 AI 代走 / 判负**——
  兜底链永不卡死）、参谋模式与强度、参谋深度（2/4/6 层）；
- 配置为空的槽位运行时自动借用对方配置（黑→红优先），消息区注明来源；
- 走子失败判负时显式终局，不软死锁。

### 6.3 大模型对战（LLM vs LLM，E-F22）

- 红黑双配置卡独立设置（可不同厂商/模型），参谋模式下红黑**各自独立棋力强度**；
- 开始前校验双方已配置；对局循环红黑交替，每手间隔可选 0/1/2/5s；
- 控制：开始 / 暂停·继续（同一按钮）/ 停止 / 新游戏；暂停在两手之间生效，在途回复作废；
- 消息区显示双方"分析"思路注解与最后着法中文记法；恢复存档后不自动续跑；
- 一方走子失败 resign 终局。

### 6.4 能力评估运行器 MatchRunner（E-F23/E-F42）

- 无 UI 的 CLI 对局运行器（`cmd/eval`）：两个走法源对打，单手超时 5 分钟，失败/无着 = 当方认输；
- 质量评估：每手用引擎最佳着法 + 评估函数算失误数（>250 厘兵）与 Top-3 命中/失随；
- 输出 JSON 报告（胜负/终局原因/总手数/双方耗时/兜底次数/着法序列），`runSeries` 多局红黑换边；
- **四 profile**：baseline-v1（基线）/ p0-prompt-v2（新提示词）/ hybrid-candidate（候选参谋）/
  hybrid-gate（护航参谋）——用于量化对比大模型棋力演进（参考结论：失误率 21%→8%→0%→0%）。

## 7. 棋谱库（记录库）

- **保存为棋谱**：四对局页均可将当前对局存入棋谱库（标题留空自动生成"日期+模式"、可填备注；
  LLM 页自动署名模型名）；从终局逆序反推起始 FEN；
- **记录列表**：标题/模式/结果/求解状态/创建时间；按求解状态筛选 chips（对局/已破解/无解/未决超时）；
  行卡右侧"操作 ▾"下拉菜单；
- **详情重放**：主变与各条解法线路独立重放（残局类默认第一条解法，对局类打开即定位保存时局面）；
  步进（首/上一/下一/末）+ 自动播放（0.5x/1x/2x）+ 中文记谱芯片点击跳转；
- **棋谱信息卡**：模式/状态/解法数/结果/起始 FEN（非标准时显示）/备注/大模型注释/求解结论；
- **操作**：进入对战（对局类从终局局面继续、残局类从起始局面重摆、已分胜负无入口、可选执方；
  棋谱来源不写自动存档）/ 导出 PGN（复制到剪贴板）/ 分享文本（复制）/ 导出 PGN 文件（含 Seven Tag
  Roster + ICCS + 残局 FEN）/ 删除（确认框）。

## 8. 残局工作室（三 Tab）

- **摆盘校验 Tab**：点击格位 + 棋子选择器轮换放置/清除，行棋方切换、调色板、橡皮、清空、
  载入初始局面、实时 FEN 预览；**放置即时校验**（将限九宫、士限斜点、象限己方半场田字点、
  兵卒不得在本方底线三排、数量上限将 1/士象马车炮各 2/兵 5、双王各一、对手不可正被将军等五条整体校验）；
- **FEN 导入**：完整 FEN 或仅棋盘字段（缺省补轮走方）；
- **求解 Tab**：载入局面 → 求解器运行（**非阻塞悬浮进度条**，求解期间棋盘仍可操作；
  限时 10s/30s/1min/3min、深度浅 5/标准 9/深 13 半着可选）→ 结果面板（**关闭按钮置顶常驻**）；
  三种结论**全部自动入库**：唯一解 / N 条破解走法（附中文记谱线路与用时）/ 无解已证明 / 限时未决；
- **识图 Tab**：粘贴或选择棋盘图片（PNG/JPEG）→ 视觉大模型识别（非流式，120s×2 超时重试，
  识别期间按钮禁用防重入）→ FEN 载入 → **强制人工校正流**（9×10 网格点击纠错、候选棋子选择器、
  重新提交或直接采用）→ 进入演示/对战；识别错误由人工把关，不静默采信；
- **大模型求解辅助**：LLM 提议首着与思路 → 引擎 `isWinningFirstMove` 接口验证首着确为胜着
  → 通过才写入求解注释；失败不影响求解主流程；
- **助手配置**：助手槽全空时运行时借用对战配置（不写入助手槽），消息区提示来源与识图风险。

## 9. 设置、安全与持久化

- **全局设置弹窗**：自动保存开关、LLM 对局设置（数值越界自动钳位）、界面缩放档位；
  持久化于 `settings.json`（数据目录 `chinese-chess-ultra-gio`）；
- **数据库**：SQLite（纯 Go 驱动，零 CGO）——存档分桶、棋谱记录、求解结论；懒打开，
  磁盘异常时按"本地存储不可用"降级、新局兜底；
- **凭据**：三槽位 API Key 走 OS keyring，回退文件权限 0600；日志/异常/UI 全程掩码；
- **外呼收口**：全部网络请求（LLM 对话/识图/语料下载）经唯一 transport 模块，带超时与取消；
  语料下载仅 HTTPS + SSRF 白名单 + zip-slip 防护；
- **异步可靠性**：所有后台任务（AI 搜索/求解/LLM 请求/批量解析/下载）带请求 ID——新局/悔棋/离开页面
  自动取消，迟到结果按 ID 丢弃；输入锁在失败/取消/离开页面时必定解锁。

## 10. 与上游版本的既定差异

| # | 差异 | 说明 |
|---|---|---|
| 1 | **重复局面裁决前置** | 长将警告/判负、重复判和/强制和在核心对局（非后期补丁）即全部到位 |
| 2 | **LLM 思维链强制关闭** | 上游思维链为可选配置；本版请求层恒发关闭参数、UI 无开关，保证流式输出可直接解析 |

其余行为与上游 v1.0.0-rc1 逐位一致（领域层为上游逐文件复制物，状态层以上游 249 个测试用例为行为锚点翻译）。

## 11. 平台与发行形态

| 平台 | 形态 |
|---|---|
| Windows | 裸 exe（单文件，无需 WebView2 运行库） |
| Linux | 单二进制 + deb 包 + AppImage（约 15MB，上游 Electron/WebKit 方案为 80MB）+ tar.gz |
| macOS | .app bundle + dmg |

构建即 `go build` 单二进制（版本号经 ldflags 注入）；CI 三平台矩阵自动测试并发布
（质量门：gofmt + go vet + `go test ./... -race` 全平台无例外）。

## 12. 范围外与已知限制

- **范围外**（沿上游口径）：多人联机、云同步、自然限着与长捉判罚、音效素材替换、国际化（UI 全中文）；
- **已知限制**（详见 `docs/KNOWN_ISSUES.md`）：
