## 消费方式注记（Gio 版特有）

- §0 通道字节承载（base64）：上游经 Wails 事件传输；Gio 版为**进程内直调**（[]byte 直接传递），base64 编解码语义保留在复制物 API 边界以维持对拍面不变——不裁剪。
- §1 语料扫描 / §6 批量解析：goroutine 分批 128 + generation 防陈旧（上游 corpusBrowser 语义）随状态层迁 Go（DR-G002，internal/state）；进度经 app 事件通道（`parser:progress`/`corpus:progress` 命名沿用并登记于 00 §4，K4 教训）。
- §5 下载器：进度可取消、半成品保留（防错 #10）经 internal/ui 挂接；SSRF 白名单与 zip-slip 防护为复制物内建，Gio 侧零改动。
- §7 演示播放器：状态机（idle→playing→paused/completed/error，上游 stores/puzzleDemo.ts 269 行）按 DR-G002 迁 internal/state；步进/自动/回退 UI 随 M6' 在 internal/ui 自绘。
- 大列表（14 万局 PGN 索引）：layout.List 虚拟化 + 分页索引（08 §长列表）。
