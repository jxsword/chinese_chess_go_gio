## 术语表（上游 11 条沿用 + Gio 版新增）

沿用上游：厘兵、内部坐标、ICCS、LLM 坐标、参谋制、strengthBlend、五层过滤、MoveSource、requestId、fenHistory、金标准。
Gio 版新增：

| 术语 | 释义 |
|---|---|
| 立即模式 | Gio 的 UI 模型：每帧全量重算布局与绘制，无框架保留控件树；状态由应用自持 |
| 事件循环（单事件循环） | UI 主 goroutine 阻塞收 FrameEvent/InputEvent/SystemCommand 的唯一循环（00 §3） |
| Invalidate | `window.Invalidate()`：请求下一帧；后台结果的唤醒原语 |
| 保留态封装 | 立即模式下把"帧间存续的状态"收敛为页面 state struct，由主 goroutine 独占（DR-G003） |
| 映照 / 复制物 | 上游 v1.0.0-rc1 领域层的逐文件副本（DR-G001）；修正回上游或登记差异，禁止就地静默改 |
| 行为锚点 | 上游 TS stores/vitest 用例作为 Go 翻译的逐用例对照基准（DR-G002） |
