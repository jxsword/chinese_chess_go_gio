## 本仓差异

无行为差异。上游-DR-005 的关闭参数预设映射（DashScope→`enable_thinking:false`；GLM-4.5+→`thinking:{type:disabled}`；其余→`enable_thinking:false` 兜底）在复制物 `internal/llm/config.go` 中恒发，**Gio 版不存在任何开启路径**（配置 UI 无开关，铁律 #G6）。

## 消费方式注记（Gio 版特有）

- §3 传输层（唯一 net/http 出口，上游-DR-004）：复制物不变；internal/ui 与 internal/state 均禁直连，外呼只经 internal/llm 包 API。
- 流式对接（§3.2 SSE）：chunk/done/error 经 app 事件通道按 requestId 分发（00 §4），OnChunk TOCTOU 窗口（K21）的防线仍是 UI 侧 requestId 二次收口——Gio 下由 internal/app 事件总线实现。
- §7 视觉识图：长任务无中途取消入口（K33 口径不变）；base64 图片承载经 internal/llm vision API，Gio 侧从棋盘绘制/截图采样得到图像字节（M6' 实现，08 文档）。
- 配置卡（endpoint 四字段 `{baseUrl,apiKey,model,preset}`）UI 在 internal/ui 自绘，凭据三槽位经 internal/storage.Credentials 掩码收口（防错 #8）。
- §9 MatchRunner 接入：cmd/eval 复制物与 M7' 评估共用，零改动。
