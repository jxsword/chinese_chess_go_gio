## 2. 自动保存与恢复状态机（语义不变，事件源改 Gio）

上游状态机照搬：页面卸载（dispose）/失焦/最小化/关闭/手动保存 → 自动保存落 mode 存档桶；进页恢复=重放逐手重建（跳脏记录语义——非法记录跳过且计数）。上游-DR-008 起始 FEN 语义随 gameVm 翻译继承（修复已在上游完成）。

**事件源映射（K13/K16 的 Gio 替代，上游 `app:lifecycle` 事件消失；v0.10.3 实测口径，M1' 落档修订）**：

| 上游事件源 | Gio 事件源 | 挂接 |
|---|---|---|
| WebView window.blur / win.on('blur') | `key.FocusEvent{Focus:false}`（实测：字段名为 `Focus` 而非预设的 Focused；窗口焦点变化经 ConfigEvent 转入事件流） | internal/app → state.OnBlur()（各平台覆盖面 M2' 手测核实） |
| win.on('minimize')（上游无，K13） | gio 无直接窗口事件（`system.ActionMinimize` 仅为发起动作）；不伴随失焦的平台兜底方案 M2' POC 核实接线 | 同上（派发通道已就位） |
| OnBeforeClose / before-quit（300ms best-effort，K16） | `*app.ClosingEvent`（实测：无 system.CommandClose；可 `Abort()` 挂起关闭）——app 收到即触发自动保存（有界等待 best-effort 语义同级），随后放行退出 | internal/app 装配 |
| 路由卸载 dispose | internal/app 页面切换事件（Router：离开页实现 `Disposer` 即调用） | state.DisposeGame(mode) |

自动保存失败口径：发即忘（K3）的 Go 对应=保存错误记日志并在界面状态条提示，**不吞错、不阻塞交互**。

**Go 形态（T2'.2 落地口径）**：`state.GameAutoSave`（autosave.go）的 Attach/Dispose 对应页面挂载/卸载；
blur/minimize 由 internal/app LifecycleRouter 派发到页面 `OnBlur/OnMinimize` → `SaveOnExit()`；
close（`*app.ClosingEvent`）走页面 `OnClose` → **同步保存**（=K16"300ms best-effort 有界等待"的 Go 对应：
本地 sqlite 单行写完成或失败即返回，随后放行退出）；页面切换 dispose → `Dispose()`（先 SaveOnExit 再注销，
与上游 game_auto_save.dart:73-79 同序）。存档写入/取档的 DB I/O 一律在后台 goroutine
（铁律 #G3），经 internal/app repo 异步代理 + 事件回执（00 §4 内部事件行）；
关闭路径的同步写是唯一主循环内 I/O 例外（有界等待语义本体）。恢复取档为异步：进页先锁输入
（防错 #5），取档回执后按 RestoreOrNewGame 决策应用并解锁；离页 Cancel(requestId) 迟到回执丢弃。

## 3. GameVm 与 fenHistory 四收口点（DR-G002 重心之一）

- 翻译源=上游 `stores/gameVm.ts`（322 行）；落位 `internal/state/gamevm.go`；行为锚点=`gameVmFenHistory.spec.ts` 全部用例逐条翻译（Go 表驱动）。
- `fenHistory []string` 长度恒 = moveHistory.length + 1，四收口点照搬上游 07 §3：

### 6.2 并发与所有权口径（Gio 单事件循环同构 Zustand 单线程）

- **internal/state 全部归 UI 主 goroutine 所有**：状态变更只发生在事件循环内（FrameEvent/输入事件/app 事件总线 drain）；后台 goroutine **禁止直写 state**——一律经 internal/app 事件通道回主循环（00 §3/§4）。因此 state 字段免锁，`-race` 兜底验证。
- **异步编排收口**：requestId 取消、迟到结果丢弃、输入锁失败/取消/dispose 解锁（防错 #4/#5）——上游 api 客户端语义由 internal/app 事件总线 + state 收口字段承接；测试锚点=上游 api/contract.spec.ts、engineClient/parserClient/solverClient.spec.ts 的语义逐条翻译为 Go 表驱动用例。
- 全局单例仅限 globalSettings；对局相关一律工厂每局一实例，页面退出即 dispose。
