## 1. 用例映射总表

- **复制物测试**（internal/ 六包 44 个 _test.go + cmd/eval）：随上游映照整体继承，已全绿（复制 commit 记录）——规则/引擎/求解/LLM/解析/存储的领域面无需重写。
- **状态层测试**（新增重心）：上游 frontend/test/ 实测 27 spec/249 用例中，stores/api/llm/storage/studio 相关的 18 个 .ts spec（173 用例）为**逐条翻译源**（DR-G002）——fenHistory 四收口（gameVmFenHistory）、自动保存恢复状态机（autoSaveRestore）、异步编排收口（api/contract、engineClient、parserClient、solverClient）、语料浏览（corpusBrowser stores 版）、演示播放器（puzzleDemo）、LLM 设置与借用（dr005/llmAssist/assistantConfig）、摆盘校验（setupRules/studioValidate）、PGN 导出快照（pgnWriter）。逐文件映射在实现各里程碑时于 PROGRESS.md 勾选登记。
- **Gio 层测试**（§4）：页面逻辑与绘制断言少量、轻量；重交互验证走手测清单制。

## 2. 专项测试（继承口径，复制物已全绿）

### 2.1 金标准对拍（双仓同源）

- `testdata/golden/` 四份 JSON 与上游**逐字节同源**（sha256 记录于复制 commit）：fen.json / moves.json / notation.json / engine.json（d5/d6 慢速集 `RUN_SLOW=1`）。
- 口径不变：全部对拍在**不传 HistoryFens** 前提下成立（上游-DR-006 受控偏差）；同分着法排序不参与；L3 三类环用例与 Electron 版期望逐条一致。
- **同源守卫**：本仓金标准只读；改动须给出上游/Electron 版依据并单独 commit；CI 可比对上游同源 sha256（可选步骤）。

### 2.2 引擎/求解器（复制物继承）

L0 Zobrist 确定性快照/增量一致/undo 复原；L1 缺省逐位一致+惩罚精确值+nodeCount 差 ≤5%；L2 注入随机源 5 场景；性能门难度 5 ≤7.5s（**显式大超时**）；求解器 6 验证 FEN。

### 2.3 LLM 管线（复制物继承 + Gio 侧断言）

mock SSE 全场景表照上游 09 §2.3（含 GLM thinking 参数断言=恒发关闭参数，上游-DR-005）；**mock 写已断开连接守卫**教训随用例继承。Gio 侧新增：internal/app 事件总线的 requestId 过滤/迟到丢弃单测（channel 语义表驱动）。

### 2.4 goroutine/存储/下载器（复制物继承 + 状态层新增）

复制物：协议 roundtrip/cancel 结算/迟到丢弃/串行 FIFO、DAO 全路径、SSRF+zip-slip 全表、**临时目录先关 fd 再删（带退避重试）**。状态层新增：自动保存状态机全路径（事件源=Gio 生命周期事件注入 fake）、四收口点、corpusBrowser 分批/generation、puzzleDemo 状态机——全部表驱动、`-race` 下跑。

## 3. 状态层测试约定（DR-G002 重心）

- 翻译纪律：上游 spec 的**每个 it/test 用例**翻译为一个 Go 测试函数或表驱动 case，用例名保留对应关系（注释标注上游 spec 文件:用例名），禁止合并/删减语义断言；上游用例数为**翻译完成度验收线**（173 条领域面）。
- mock 注入：上游 vitest 的 mock 传输（协议核心 fake）→ Go 侧同型 fake（`{id,type,payload}` 消息形状注入）；时钟/随机源显式注入；存储用 `OpenDaoInMemory`。
- 快照测试仅三类协议面：提示词（复制物已有）、PGN 导出、JSON 报告——基准与上游同源。

## 4. Gio 层测试（新形态，轻量）

- **事件总线/装配单测**：internal/app 的路由切换、生命周期事件派发（FocusEvent/system.Command 注入 fake）、requestId 过滤——纯 Go 表驱动（不渲染）。
- **绘制/布局冒烟（可选）**：`gioui.org/headless` 离屏窗口渲染若干帧，断言不 panic + 帧产出；需 GPU/软渲染环境的 CI 适配由 M0' POC 结论决定是否进质量门（默认仅本地）。
- **widget 交互**：通过向窗口注入事件（`app.Window().Event` 注入测试不可行时用状态级单测替代）——原则：**能在 state 层测的逻辑不进 Gio 层测**。
- 不做像素级 golden image 断言（维护成本高、跨平台渲染差异大）；视觉正确性由手测清单制承担。

## 5. E2E 差异声明（上游 §2.5 的替代）

上游 Playwright 冒烟链路（启动→主页 7 入口→双人走一着→悔棋→新游戏→棋谱库）在本仓**无浏览器面可自动化**，替代为：
1. 状态层等价用例（上述链路的状态迁移断言全部可表驱动）；2. Gio headless 冒烟（若 POC 采纳）；3. **手测清单制**：每里程碑 PROGRESS.md 列出可点击的手测步骤（对照 08 防错清单逐项），用户验收流（11 §5）执行。LLM 相关手测一律 mock 配置/真实端点由用户自选。

## 6. 测试目录与工具约定

```text
internal/**/*_test.go          # 与被测包同目录（Go 惯例；复制物 + 状态层新增）
internal/app/*_test.go         # 事件总线/装配单测
internal/state/*_test.go       # DR-G002 翻译测试（上游 spec 对应）
internal/*/testdata/           # 包级测试资产（xqf 样例/求解 FEN，复制物）
testdata/golden/               # 跨语言金标准（复制物，只读，同源 sha256 守卫）
```

- **CI 平台性教训内置为规范**（继承上游-DR-012/K34 与 Electron 版三项）：① mock 写已断开连接必须守卫；② 临时目录清理先关 fd、带退避重试（Windows 句柄滞后）；③ 性能类用例显式大超时（防 CI 负载假超时）；④ sqlite 句柄 `t.Cleanup` 关闭（Windows 不可删打开中的文件）；⑤ 0600 断言仅非 Windows 执行（NTFS ACL 承载语义）。
- 并发测试一律 `go test -race`（全平台无例外，上游-DR-012）。
